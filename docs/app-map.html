At a glance

Shell

  • Dark top bar with the Lio mark.
  • Tabs: Overview, Requests, New Request, Approvals, Suppliers, Articles, Organization.
  • Email, role and Sign Out on the right.

Roles

  • Requester sees 5 tabs. No Approvals, no Organization.
  • Buyer adds Approvals.
  • Admin sees all 7.

Data today

  • Acme has 1,920 articles and 120 suppliers.
  • No requests existed. I added one sample request for these shots.
  • Euro amounts, German number format.

Screens

Sign in

/sign-in, /sign-up
  • Email and password.
  • Link to sign up.
  • Dark background, white card.

Overview

/dashboard
  • Four counters: Total, Open, In Progress, Closed.
  • Three pie charts: by status, closed by group, all by group.
  • Recent requests table with View All and New Request.

Asks that touch it

  • 3: the by-group charts show wrong categories today.

Requests

/dashboard/requests
  • List of all requests in the org.
  • Opens the request detail.

New Request

/dashboard/new-request
  • Optional PDF upload, up to 10 MB. AI fills the form.
  • Request details: requestor, department, title.
  • Vendor: name, VAT ID, commodity group dropdown.
  • Order lines: free text, unit price, amount, unit.
  • Live total, then Create Request.

Asks that touch it

  • 1: the upload and extraction live here.
  • 2: order lines never look at the catalog.
  • 3: the commodity group gets set here.

Request detail

/dashboard/requests/[id]
  • Two badges: status (Open) and approval (Pending).
  • Approve, Reject, Edit, Delete.
  • Status switch: Open, In Progress, Closed.
  • Details, order lines, activity timeline.
  • Original PDF shown on the right.

Asks that touch it

  • ★: the activity timeline is where "auto-approved" goes.
  • 2: could show the catalog price next to each line.

Approvals

/dashboard/approvals
  • Pending queue for buyers and admins.
  • One row per request: title, requestor, vendor, group, total.
  • Approve or Reject inline.

Asks that touch it

  • ★: everything lands here today, even €240.

Suppliers

/dashboard/suppliers
  • 120 suppliers with category, country, VAT ID.
  • Search by name, filter by category.
  • Banner: 0 of 120 have a description. Out of scope.

Articles

/dashboard/articles
  • 1,920 articles with negotiated unit prices.
  • Article number, description, supplier, unit, quantity.
  • Search by description or number. 25 per page.

Asks that touch it

  • 2: this is the catalog to suggest from. Its search is a starting point.

Organization: Members

/dashboard/organization
  • Invite by email with a role. No emails go out.
  • Member list with role badges.

Organization: Settings

/dashboard/organization
  • Two toggles: require VAT ID, require department.
  • This is the only per-org config in the UI.

Asks that touch it

  • ★: the approval threshold setting belongs here.
  • 3: Acme's category rules could live here too.

What this tells us

Extraction

  • One entry point: the upload on New Request.
  • Fix it there, and nothing else in the UI changes.

Catalog

  • The data exists: 1,920 priced articles.
  • It's just never used when someone writes a request.

Config

  • Org Settings already exists.
  • Threshold and category rules can extend it. No new screens.
